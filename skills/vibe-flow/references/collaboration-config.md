# 协作配置与本次执行约定

配置提供可讨论的建议。具体工具说明是配置中的数据，不要求安装另一份派工 skill。调用前读所选工具的说明，直接使用它的命令、输出和退出码。

## 读取建议

从插件根运行（`python` 代表本机已确认的解释器，Windows 可使用其绝对路径）：

```text
python skills/vibe-flow/scripts/collaboration_config.py --organization review-execute
```

此脚本只读 JSON、检查引用与说明文件是否存在、打印建议及工具不可用原因；不执行命令，不替用户确认，不生成任务约定。配置选择顺序：显式 `--config`、环境变量 `VIBE_FLOW_COLLABORATION_CONFIG`、`~/.vibe-flow/collaboration.json`、随包 `config/collaboration.json`。只有可选用户覆盖不存在才使用随包建议；显式路径不存在、覆盖坏值、空环境变量均报错退出，绝不回退模型。

四类登记：`tools` 保存可执行入口、已核版本和说明路径；`agents` 保存工具引用、工具原生 agent 选择名、模型、思考程度和 mode 建议；`roles` 引用 agent；`organizations` 给出角色组合和串行/并行建议。它们都是完整配置，覆盖文件不作隐式合并。不将任意模板、shell 片段或执行协议塞进配置。

路径相对配置文件目录解析；`${PLUGIN_ROOT}` 由读取脚本位置推导插件根，`${CONFIG_DIR}` 为该配置文件父目录，`${ENV:NAME}` 读取已设置的环境变量，`~/` 用当前进程用户目录。未知/空符号报错，不支持 `$VAR`、`%VAR%` 或命令替换。`--config` 和环境变量中指定的相对文件路径基于调用者工作目录。机器绝对路径只保存在本机覆盖中。总览仅标记缺失说明的工具不可用；选中组织依赖该工具时明确失败，其余组织照常。必需结构或路径符号损坏仍整体失败。bare 可执行命令名保留；含路径/符号的可执行入口按同一基准解析且拒绝未知符号，但不运行或探测工具。

随包常规审核/执行采用已有设置证据的同一 agent 两组模型；头脑风暴保留原先多模型组合的可选建议，尚未认证的成员在配置中明确标记不可验证。该建议需用户选择并完成认证/能力验证，不能把未验证状态当成可执行授权。

模型、effort、mode 的有效范围由当前工具和适配器提供，读取器只检查必需字符串，不能证明服务端接受。调用者先查询能力；未知、不支持、认证失败、回执未证明接受都停止受影响操作，不替换模型。随包建议中的模型与权限名称也需本机验证，不能因为配置读取成功就标记可用。

## 确认并记录

每项任务开工前，集中给出当前建议，请用户确认：各角色 agent、模型、思考程度、分工、串行/并行与是否监工。只问本次尚未确认的部分；已明确指定、授权沿用或委托 AI 决定的部分直接记入。简单任务可以一句确认，不反复填表。未确认前不派发。

确认后优先写入现有 HANDOFF 的「本次执行约定」，无 HANDOFF 时按 §6 建只含本次执行约定的 HANDOFF；微脚本用同目录 `<脚本名>.HANDOFF.md`，收尾按文档规则迁移有效结论后删除。记录：

- 目标、范围、约束、输入文件与验收方法。
- 用户确认来源、负责人/审核者/执行者及 agent、模型、effort、组织方式；不需要的角色明确省略。
- 绝对工作目录、允许修改的文件、真实权限设置及其限制、提交/发布边界。
- 工具版本、说明路径、完整实际命令；本次会用到的查询/获取结果/续接/取消方法。
- 每次调用后的原生会话 ID、命名会话、工具原始回执与结果证据位置。

只复制本次实际设置与命令，不把工具手册整份抄进去。执行约定不是运行引擎。更换 agent、模型、effort、权限或组织方式前集中确认受影响项，然后更新约定；普通子任务沿用已授权设置，不重复询问。

## 恢复

先读原任务约定和现有结果，定位同一工作树、工具、适配器启动配置和会话 ID；查询活动状态与原始历史，再决定等待、取消或续接。外层超时、进程退出、空输出都不能当成「没派出去」。恢复使用任务已经确认的设置，不读取最新建议来替换它；重连后重新核验模型、effort、权限与会话身份，防止适配器恢复时重置权限。

原生工具可能在后端会话失效时新建会话，必须核对恢复前后 ID。若原会话无法恢复，明确报告上下文缺失，用户确认重新开始后才新建。执行者回执由负责人检查实际文件和有意义的测试。工具返回成功不等于验收通过。

当前随包工具的安装、原生命令示例、Windows argv 与验证方式见 [acpx 接入](acpx.md)。主流程不据此绑定工具。

随包工具说明首先指向本插件接入页，那里记录版本、原生设置命令与已知限制，再按需进入上游原文；避免绕过已知恢复限制。
