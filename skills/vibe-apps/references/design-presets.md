# 本机界面预设

新建工业上位机、设备配置或调试工作台时，用户指定的风格和项目已有的 DESIGN.md 优先。其余情况下检查用户主目录下的 `~/.vibe-flow/design-presets/industrial-desktop/`。预设装好后，读取其中的 `DESIGN.md`、`tokens.css` 和本次需要的 `preview/` 样例。预设未安装时沿用常规设计流程。

按首要原则、实际控件尺寸和样例组织页面。只选与任务相关的布局。将所用 token 按本 skill 的格式写入项目 DESIGN.md，原生界面保留对应的控件尺寸，效果图按用户确认的样例校验密度。已有项目的小改和其他类型应用沿用自己的设计。

本机预设是一份完整的静态目录，可直接读文件出 HTML。用户要求在 OpenDesign 生成、保存或核对继承时，按 [OpenDesign 原型流程](open-design.md) 操作。
