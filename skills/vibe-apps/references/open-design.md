# OpenDesign 原型流程

## 复用已有设计

1. 先读项目 DESIGN.md 和用户确认的 HTML。设计在 OpenDesign 时，按当前工作区的名称或 ID 找已确认的体系，只取本次用到的首要原则、设计 token 和样例。
2. 复用样例的布局与交互。工具页保留直接操作所需的内容。目录导航可以参考多层目录树。展开后有多列需要填写时，参考可编辑树形表格，验证折叠再展开仍保留未提交的输入。
3. 对照原稿实际值检查字号、行高、控件高度、按钮和表格的纵向留白。布局承担信息分组，只放帮助用户操作或理解状态的文字。

## 选择交付路径

- **只看小型页面效果**。当前会话直接按已确认的规范出一个可点击的 HTML。需要 OpenDesign 收录或预览时，使用工作区已有的导入方式，复用这一份原型。
- **由 OpenDesign 生成或验证继承**。使用工作区已配置的入口，集中做一次预检，确定服务是否就绪、设计体系 ID 和明确的生成工作流。复用已启动的服务。服务确实未运行时，用已知入口启动一次，在配置的时间预算内等就绪。
- 提交前固定工作流、设计体系和请求标识。遇到恢复或重试，先查同一请求，已有任务就继续查状态。预检或启动超时后，直接报告失败所在和已有进展，停止自动重连、换端口、换入口或重装集成。启动耗时和生成耗时分别记录。
- 验证继承时，查 OpenDesign 实际绑定的设计体系和生成结果，再用浏览器检查原型的密度和核心操作。
