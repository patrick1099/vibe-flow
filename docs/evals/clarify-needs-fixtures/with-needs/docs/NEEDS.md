# NEEDS —— 发票整理小工具

> 真需求锚：**我每个月手动把几十张 PDF 发票改名、抄金额进表格，烦死了，想把这段重复活省掉。**
> 场景：个人报销 / 小公司财务，一个文件夹里堆着当月所有 PDF 发票。

## 当前需求区

### 第一版非做不可
- **把一堆 PDF 发票批量改成看得懂的名字**（`日期_金额.pdf`），不用再一张张手动重命名。
- **汇总当月所有发票金额出一张总表**（CSV），省掉手动抄金额那一步。

### 必须达到的及格线
- 改名：给一个文件夹，跑完所有 PDF 都按 `日期_金额.pdf` 改好名，改错的能看出来。
- 汇总：跑完在同目录出一张 `汇总.csv`，每行一张发票、有金额，末尾有合计。

### 做法可以替换
- 汇总完自动把总表**发邮件给财务**（也可以先手动发，这条只是图省事）。
